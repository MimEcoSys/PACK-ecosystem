## Что это

Это **source-of-truth** для области «Экосистема развития интеллекта». **Экосистема развития интеллекта** объединяет организации, людей, сообщества и технические системы для совместного развития людей и ИИ. В её состав входят организация МИМ, сообщество, ИТ-платформа, Aisystant Corp, персональные и командные ИИ-среды и другие участники. МИМ является организацией внутри экосистемы; ИТ-платформа и IWE являются её техническими компонентами.

**На уровне отдельного человека развиваются три системы: человек, его ИИ-среда и «железный человек» — система их совместной работы. Четыре уровня рассмотрения экосистемы: отдельный человек, команда, сообщество и общество.** Полное описание уровней и состава культуры: [границы области](pack/ecosystem/01-domain-contract/01A-bounded-context.md).

## Ключевые понятия

| Понятие | Описание |
|---------|----------|
| **Экосистема** | Связанная система компонентов для развития интеллекта |
| **Бесшовность** | Отсутствие барьеров между компонентами |
| **Компонент** | Ресурс/сервис/сообщество в экосистеме |
| **Путь развития** | Траектория через компоненты |
