# [ECO.MAP.004] Указатель объектов внимания

**Для кого:** исполнитель любого рабочего продукта (РП) и его ИИ-агент, проверяющий. **На какой вопрос отвечает:** каким словом назвать то, с чем работаю, где это уже записано и как добавить новое, чтобы не заводить свой словарь. **Чего здесь не искать:** самих записей — указатель только называет, где они лежат. Правило, что работа обязана оставить в описаниях, — ECO.ARCH.003.

Указатель новых понятий не вводит. Если нужного вида объекта здесь нет, новый реестр не заводится: вопрос идёт владельцу указателя.
