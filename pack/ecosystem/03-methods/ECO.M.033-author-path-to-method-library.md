# ECO.M.033: Путь автора в Библиотеку методов

### Definition
Метод, по которому автор превращает свой способ действия в запись Библиотеки методов, находимую и применимую другими, с сохранением авторства, редакции и лицензии.

### Purpose
Чтобы метод, который работает у автора, мог проверить и применить кто-то другой, не потеряв источник.

### Forces
| Force | Tension |
|---|---|
| Открытость входа ↔ доверие к записи | Принимать всех, но показывать читателю, кто и как метод проверил |
| Один источник правды ↔ удобство читателя | Метод остаётся у автора, Библиотека хранит сведения и указатель |

### Inputs
Метод в любом виде (текст, регламент, практика); владелец и редакция; лицензия.

### Steps
1. Убедиться, что это метод: повторяемо, описываемо, есть входы и выходы, не зависит от инструмента, не сценарий с нумерованными шагами.
2. Оформить описание по шаблону карточки метода (SPF): определение, назначение, входы, выходы, роли, различения, типовые ошибки, статус.
3. Указать грани для поиска: предметная область, объект воздействия, кто исполняет, условия применимости, результат; отдельно указать уровень источника.
4. Указать, чей метод, в какой редакции, под какой лицензией; закрепить редакцию.
5. Подать запись запросом на слияние в Библиотеку; хранитель проверяет формат, владельца, редакцию, лицензию, отсутствие запрещённого содержимого.
6. Присвоить уровень доверия: не проверен, проверена карточка, есть полевые свидетельства, внешний источник со ссылкой.
7. Собирать свидетельства применения: кто, в каких условиях, с каким результатом; обновлять уровень доверия.

### Проверка
Независимый читатель по записи (без обращения к автору) находит автора, редакцию, лицензию, область применимости и уровень доверия, затем применяет метод и сообщает, что получилось; расхождение с описанием возвращается автору.

### Outputs
Запись Библиотеки со ссылкой на источник у автора; карточка метода в паке автора; запись об уровне доверия.

### Related Methods
ECO.M.034 (создание пака, где метод живёт), ECO.M.032, ECO.M.017 (передача методов через экосистему), РП-608 (проект Библиотеки методов), SPF (шаблон карточки).

### Key Distinctions
Метод ≠ описание метода ≠ исполнитель в роли ≠ работа; описание метода не доказывает применения; запись Библиотеки не копия метода.

### Bias-Annotation
| Bias | Direction of distortion |
|---|---|
| Описание принимают за подтверждение | Аккуратная карточка читается как проверенный метод; уровень доверия различает |
| Автор оформляет то, что легко описать | Тяжёлые для формализации методы остаются вне Библиотеки |

### Failure Modes
Копия чужого свода вместо ссылки; запись без редакции; свидетельство «метод помог» принято автоматически.
