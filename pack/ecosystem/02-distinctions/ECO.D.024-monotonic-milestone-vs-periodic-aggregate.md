# ECO.D.024: Монотонная веха ≠ Периодический агрегат

## Различение

| Параметр | Монотонная веха | Периодический агрегат |
|----------|------------------|------------------------|
| **Природа факта** | Конститутивна — рождается актом фиксации | Производна — выводится из истории/прошлого |
| **Протухание** | Не протухает; однажды случившееся остаётся навсегда | Протухает/обновляется по периоду (неделя, месяц) |
| **Писатель** | Есть — конкретное действие в конкретный момент | Может отсутствовать — вычисляется системой |
| **Соответствие принципу «N+1 невозможен без N»** | Соответствует — накопительная карта прогресса | Может нарушать — протухающий статус создаёт регресс |

## Антипаттерн

Факт чек-листа участника («выбран личный проект», «зафиксирован первый рабочий продукт недели») предлагается смоделировать по аналогии с периодической метрикой активности («продукт недели», обновляемый/протухающий статус «текущей недели»). Аналогия онтологически некорректна: у периодического агрегата нет собственного писателя, он производен от прошлого; у факта чек-листа участника есть писатель и момент фиксации — это разные категории.

## Правило

Факт чек-листа моделируется как монотонная веха (читатель `EXISTS`, без протухания), если удаление факта при бездействии участника создало бы регресс и нарушило принцип «N+1 невозможен без N» (нельзя подтвердить вторую ступень, не подтвердив первую). Регулярность/периодичность — если она значима — выносится ОТДЕЛЬНЫМ фактом-счётчиком, не смешивается с монотонной вехой. Технические поля вроде `period_id` в payload события допустимы ради идемпотентности записи, но не меняют семантику чтения факта.

## Тест различения

«Если участник период ничего не делал — факт должен исчезнуть?» Нет → веха (монотонный, конститутивный). Да → агрегат/счётчик (производный, протухающий).

## Применимость

Любое проектирование фактов участника в чек-листах/картах прогресса экосистемы, где нужно решить, накапливается ли факт бессрочно или обновляется по периоду — прежде всего в конвейере вовлечения (выбор проекта, первый рабочий продукт, дальнейшие вехи трека).
